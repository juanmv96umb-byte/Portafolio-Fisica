# Rediseño Completo del Portafolio de Física Aplicada

**Design Read:** Portafolio estudiantil académico para evaluadores/profesores, con lenguaje visual dark-premium, paleta esmeralda + zinc oscuro, tipografía Outfit + Space Grotesk, layout asimétrico, responsive mobile-first.

**Dials:** VARIANCE: 7 | MOTION: 5 | DENSITY: 3

---

## Cambios en `index.html`

1. **Tipografía:** Reemplazar Inter por **Outfit** (display/body) + Space Grotesk (headings). Google Fonts link actualizado.

2. **Iconos SVG:** Reemplazar TODOS los emojis (🏠📋📚🔬📝✏️👥🧠📖📁👤) por **iconos SVG inline** estilo Phosphor/HugeIcons (24px, stroke 1.5). Sin dependencias externas, SVGs directos en el HTML.

3. **Portada asimétrica:** Reestructurar la portada:
   - Layout left-aligned en vez de centrado
   - Texto institucional compacto en un "chip" superior
   - Título con gradiente esmeralda→cyan
   - Info del estudiante en cards horizontales (no lista vertical)
   - Grid de accesos directos tipo **bento** (celdas de tamaño variado: 2 grande + 3 medias + pequeñas), no 3x3 uniforme

4. **Sidebar:** Mantener estructura funcional pero:
   - Agregar clase `glass-effect` para blur + borde sutil
   - Indicador activo con barra lateral animada (no solo background)
   - Mejorar la jerarquía visual con separadores más sutiles

5. **Topbar:** Agregar un indicador de sección actual más visible y un pequeño avatar circle.

6. **Añadir grain texture:** Un `<div class="grain">` fijo con pseudo-elemento SVG noise para dar textura visual premium.

### Nuevos componentes visuales
- **Grain texture overlay** (fijo, pointer-events: none)
- **Ambient orbs** con colores esmeralda/cyan (no púrpura)
- **Glass sidebar** con `backdrop-filter: blur(20px)` + `border-white/5`
- **Active indicator bar** en sidebar (barra izquierda animada)
- **Bento grid** para accesos directos (grid-template con áreas nombradas)
- **Shortcut cards** con hover: translate + glow effect
- **Mejor scrollbar** personalizado
- **Better transitions** usando `@starting-style` donde sea posible

### Responsive (mobile-first)
- **< 768px:** Sidebar como drawer con overlay blur, portada single-column, bento grid colapsa a 2 columnas
- **768-1024px:** Sidebar colapsable, portada con más espacio
- **> 1024px:** Layout completo, bento grid con variación de tamaños

### Animaciones
- **Entrada de cards** con stagger (30-80ms entre items)
- **Hover en shortcut cards:** `translateY(-4px)` + `box-shadow` glow esmeralda
- **Active press:** `scale(0.97)` en todos los botones
- **Dropdown nav:** `max-height` con ease-out custom
- **Portada card entry:** `translateY(20px) scale(0.98)` → normal
- **Ambient orbs:** Animación lenta 20-30s, colores esmeralda
- Todas las animaciones respetan `prefers-reduced-motion`
